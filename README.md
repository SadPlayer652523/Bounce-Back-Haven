# Bit-Bounce

A concept for bouncing to get on platforms to complete puzzles

# Features

- Bounce and Trick Up
- Smooth transitions
- Fun short puzzles with the bounce ability (and some surprises)

# Controls (Keyboard Only)

- D to jump
- Arrow keys to move
- Down key to crouch
- Down kry + D to Spindash
- A key in the air to bounce
- A
